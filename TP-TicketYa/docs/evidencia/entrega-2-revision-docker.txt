## 5. Correlación real en Loki

Se envió una request con un `X-Correlation-Id` nuevo y se consultó Loki:

```bash
CORR=d9d908bd-3ccc-4911-aa32-a5a5e68aec1c
curl -s -o /dev/null -H "X-Correlation-Id: $CORR" \
  'http://localhost:8080/api/catalog/events?size=2'
```

Consulta:

```logql
{container=~"ticketya-full-.*"} | json | correlationId="d9d908bd-3ccc-4911-aa32-a5a5e68aec1c"
```

- `ticketya-full-api-gateway-1` → `RequestLoggingFilter` / `request completada`.
- `ticketya-full-catalog-service-1` → `CorrelationFilter` / `request completada`.
